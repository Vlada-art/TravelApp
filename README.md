# TravelApp (SmartTrip)

Мобильное приложение для планирования путешествий (Android, Kotlin, XML).

**Практическая работа 3: локальная база данных.** К прототипу из практической работы 2 (16 экранов) подключена локальная база данных Room (надстройка над SQLite).

## Что реализовано

- **Пользователи** (таблица `users`): регистрация (Create), вход (Read), изменение имени и пароля в личном кабинете (Update), удаление аккаунта (Delete). Пароль хранится в виде хэша SHA-256.
- **Избранное** (таблица `favorites`): сердечки на экранах отелей, ресторанов, пляжей, развлечений и страницы Пхукета сохраняют места в базу (Create), экран «Сохранённые» читает их из базы (Read) с фильтрами «Все / Отели / Рестораны / Места / Маршруты», повторное нажатие на сердечко убирает место (Delete). У каждого пользователя своё избранное.
- **Маршруты**: кнопка «Сохранить маршрут» на экране карты маршрута сохраняет маршрут в избранное. Сохранённый маршрут открывается из «Сохранённых» на вкладке «Маршруты».
- Остальные данные (города, описания, подборки) статичные.

## Требования

- Windows 10/11 (на Linux и macOS тоже работает, команды ниже)
- JDK 17 (входит в Android Studio)
- Android SDK (устанавливается вместе с Android Studio)
- Интернет при первой сборке (Gradle скачивает зависимости)

## Сборка apk из командной строки

1. Откройте терминал в корне проекта (папка, где лежит файл `gradlew.bat`). В Android Studio это вкладка **Terminal** внизу окна.
2. Выполните команду:

    - Windows, командная строка (cmd):
      ```
      gradlew.bat clean assembleDebug
      ```
    - Windows, PowerShell:
      ```
      .\gradlew.bat clean assembleDebug
      ```
    - Linux/macOS:
      ```
      ./gradlew clean assembleDebug
      ```

3. Дождитесь сообщения `BUILD SUCCESSFUL`. Первая сборка может занять несколько минут.
4. Готовый файл: `app/build/outputs/apk/debug/app-debug.apk`

Если появляется ошибка `JAVA_HOME is not set`, укажите путь к JDK 17, например в PowerShell:

```
$env:JAVA_HOME = "C:\Program Files\Android\Android Studio\jbr"
```

## Установка на устройство

- **Эмулятор:** перетащите `app-debug.apk` в окно запущенного эмулятора.
- **Телефон:** включите «Отладку по USB» и выполните
  ```
  adb install -r app/build/outputs/apk/debug/app-debug.apk
  ```
  Утилита `adb` лежит в папке `platform-tools` Android SDK (в Windows обычно `%LOCALAPPDATA%\Android\Sdk\platform-tools`).

## Как пользоваться

1. Зарегистрируйтесь (имя, email, пароль от 6 символов) или войдите.
2. Откройте Пхукет на главном экране, перейдите в категории и отмечайте места сердечками.
3. Откройте «Сохранённые» в нижнем меню: места лежат в базе, их можно фильтровать по категориям.
4. Соберите маршрут (кнопка «Собрать маршрут»), откройте его и нажмите «Сохранить маршрут».
5. В «Личном кабинете» можно изменить данные, выйти из аккаунта или удалить его.
